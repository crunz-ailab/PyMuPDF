## Summary

Use `top` / `bottom` when `Table._get_header().row_has_bold()` checks whether a cached character is inside a table row. The row rectangle uses top-down page coordinates, but this helper currently compares it with the character's CTM-transformed `y0` / `y1` values.

On an ordinary unrotated page, this can both miss a genuinely bold first row and treat unrelated, vertically mirrored bold text as belonging to that row. As a result, an otherwise correctly detected table can receive the wrong internal/external header.

This is a separate occurrence of the coordinate mismatch discussed in #5092 and PR #5096. Credit to Hao-ActuaViz for that report and BetterAndBetterII for the `chars_in_rect()` patch. This PR only addresses `row_has_bold()`; it neither duplicates that patch nor claims to resolve the open-table detection issue.

## Change and scope

```diff
- if rect_in_rect((c["x0"], c["y0"], c["x1"], c["y1"]), bbox)
+ if rect_in_rect((c["x0"], c["top"], c["x1"], c["bottom"]), bbox)
```

The full-containment predicate, row bounds, and tolerances are unchanged. Nearby or partially overlapping characters do not become eligible simply because they are near a table. There are no changes to snapping, border completion, candidate grouping, `chars_in_rect()`, or table geometry.

## Reproduction and tests

The added parameterized test constructs a closed 2-by-2 grid in memory, with no external PDF dependency. It covers four cases at two vertical positions:

- A bold first row with ordinary text above: keep the first row as the internal header.
- A nonbold first row with unrelated bold text at the mirrored vertical position: retain the actual external header.
- An ordinary external-header control.
- An internal-header control with no text above.

Each case asserts the table bbox, all four cell rectangles, extracted cell text, header names, and `header.external`.

For the first case, the cell text stays `[['Header A', 'Header B'], ['value A', 'value B']]`. Before the fix, the header is incorrectly `['Above A', 'Above B']` with `external=True`. After the fix, it is `['Header A', 'Header B']` with `external=False`.
